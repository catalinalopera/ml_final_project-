# 🧠 Proyecto de Inteligencia Artificial: *[Clasificación Binaria]*

## 📘 Descripción
Este es un proyecto académico que busca construirse a la par con los estudiantes de Inteligencia Artificial de una Academia. El objetivo es lograr la facilitación de los contenidos y su puesta en práctica.   
---

## 🚀 Objetivos
- Construir un ejercicio de clasificación binaria que garantice un accuracy mayor al 90%.  
-  Integrar herramientas que facilitan el machine learning devOps como DVC (Data Version control - para versionar datasets), MLFlow (Trazabilidad de Experimentos)- Gradio para construir interfaces gráficas - Hugging Face para alojar el proyecto y GitHub Actions para simplicar y automatizar flujos de trabajo. 
---

## 🧩 Estructura del Repositorio
├── data/ # Conjuntos de datos brutos y procesados
├── notebooks/ # Experimentos y análisis exploratorio
├── src/ # Código fuente en python (modelos, scripts, etc.)
├── models/ # Modelos entrenados y checkpoints
├── requirements.txt # Dependencias del proyecto
├── README.md # Este archivo
